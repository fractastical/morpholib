## Pass 3 additions (2026-10-19)

- `coccosphere_contact_vesicle_tension_reference.json` — parameter table and literature anchors for the two Pass 3 extensions of the script. **Every constant carries a `provenance` tag** (`classical_formula` / `model_assumption`); none of the contact-model constants is a coccolith-specific measurement, and they are exposed as a $\sigma_{\text{lock}} \times$ overlap regime sweep rather than tuned.
  - *Contact model* (Jaya et al. 2016 remediation item): reduced lumped-plate finite element on the spherical-Voronoi coccosphere tiling — rigid coccolith plates with one radial DOF, Reissner (1946) shell point-load stiffness $k = 4Eh^2/(R\sqrt{3(1-\nu^2)})$ as the membrane path, suture lap-joint shear springs $k_{ij} = E h \ell_{ij}(\phi_{\text{ov}} + \phi_{\text{res}})/L_{\text{spoke}}$, slide threshold $\mu N_{ij} + \sigma_{\text{lock}}\ell_{ij} d_{\text{ov}}$, plate fracture threshold $\alpha_p P_i/h^2 > \sigma_f$, cascade-resolved event sequence (slide → arrested fracture → punch-through) and cell-exposure criterion. It is **not** a continuum 3D FEM.
  - *Vesicle rim tension model* (baseplate eccentricity remediation item): 2D Laplace balance $\tau(\psi)\kappa(\psi) = p$ on the Golgi coccolith-vesicle rim with anisotropic cytoskeletal line tension $\tau(\psi) = \tau_0(1 + (\lambda-1)\sin^2\psi)$, exact support-function solution $b/a = (2+\lambda)/(1+2\lambda)$, verified by area-conserving contour relaxation. $\lambda^* = 1.656$ is **inferred** from the SEM aspect ratio $b/a = 0.8478$ ($e = 0.5303$); no independent measurement of vesicle rim tension anisotropy exists.
- `pass3_citations.bib` — BibTeX for the additional classical reference (Reissner 1946; DOI not re-verified offline).

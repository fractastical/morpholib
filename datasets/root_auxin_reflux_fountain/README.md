# Reverse-Fountain Root Tip Auxin Reflux Capacitor & PLETHORA Meristem Zonality Dataset (`datasets/root_auxin_reflux_fountain/`)

Reference dataset and empirical *Arabidopsis thaliana* primary root apex confocal micrograph for **MorphoEval Slot 038 (`grieneisen-root-auxin-reflux-fountain`)**, implemented in `2014-grieneisen-root-auxin-reflux-fountain.py` and formally verified in `morphoeval/lean/loops/Loop_038_root_auxin_reflux_fountain.lean`.

## Pass 3 model status (what is literature-anchored and what is calibration)

- **Solved, not assembled.** Pass 2 assembled an analytical auxin field whose per-regime QC amplitudes were the reference-table values; Pass 3 solves the Grieneisen cellular PIN-permeability operator (`build_pin_lattice_operator`) as a sparse linear steady state, so all six regimes are emergent (WT 113.6× shoot at z = 52.5 µm; decapitation retains 92.5 %; k_lat = 0 collapses to 0.18× WT; NPA 1.10×; QC ablation + Xu-2006 respecification regenerates the maximum at 112.5 µm).
- **Unit correction.** `k_lat` and `k_col` are membrane *permeabilities* (µm/s) like `v_s`, `v_e`, not first-order rates (1/s) as labelled in Pass 2; `D` is the passive cell-to-cell diffusion coefficient and defaults to 1.5 µm²/s (not the Pass-2 12.0) so that PIN-mediated permeability exceeds passive exchange, as the Grieneisen model requires.
- **Literature-anchored defaults:** cell cycle 17 h, mature cell length 160 µm, EZ peak relative growth 0.45 /h (Beemster & Baskin 1998), tipping-point angle 40° (Band 2012, imposed).
- **Calibration choices without a literature value:** `D`, `v_s`, `v_e`, `k_lat`, `k_col`, `mu`, `sigma`, `J_in`, `K_aux`, `D_plt`, `gamma_plt` (the last three tuned so WT z_MZ / z_EZ land near the Pass-1 table 255 / 390 µm), `L_BIRTH_UM`, `G_MAX` (tuned to a ~2-fold lateral auxin ratio), `TAU_GROWTH_RESP_H`.
- **Known disagreements (disclosed, not tuned away):** NPA gives spatially uniform auxin σ/μ that saturates PLT induction (z_MZ = L, table says 0); the sine-law bending reaches the 40° tipping point at 5.55 h vs Band's ≈2 h; the growing lattice produces 82 µm/h vs ≈180 ± 80 µm/h; the emergent WT stele gradient is steeper than the Pass-1 table profile (0.20 vs 0.54 at z = 90 µm).

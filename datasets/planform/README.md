## Bioelectric Series Fixture (`planform_bioelectric.py`, v3 evidence layer)

Flags written from the database as read on 2026-10-18:

- `placeholder_sample_count`: `ResultSet.Num` ∈ {0, 1} (all of S9 except experiment 520; experiment 324).
- `regen_period_zero`: `ResultSet.RegenPeriod = 0` (all of S4 and S5).
- `conflicting_control_semantics`: experiment 434 (octanol from 0 h stored at 0 % double head vs. 100 % in 418). Excluded from fits by default via `series_records()`.
- `drug_window_unspecified` (start = end = 0: Oviedo octanol rows, Beane Fig. 6B), `drug_window_end_unspecified` (start > 0, end = 0: S4 onset rows, Nogi 2005 rows), `drug_window_inconsistent_within_series` (Nogi 2005 rows 322, 324–328 store 2.0/0.0 d while 329 stores 0.0/2.0 d), `drug_window_pre_amputation` (experiment 523, PZQ from −2 d).
- `multi_drug_cotreatment` (experiment 413, ivermectin + chloride), `zero_frequency_outcome_row`, `control_record`, `supplementary_record`.

Experiments 424–433 (Oviedo 2010 Fig. 1C lateral geometries) fall inside the queried id range but are not part of S1–S9; they are listed by id only under `excluded_experiments`.

`damaged/` holds five negatives, each the full fixture with exactly one injected fault (`bad_frequency_sum`, `missing_notice`, `unknown_morphology_id`, `sha_mismatch`, `unknown_mechanism_class`), plus `manifest.json` with the expected validator error code and SHA-256 of each file. A consumer whose self-test accepts any of them is broken.

The Lobo Lab notice is reproduced in `notice_text` with the same restriction clauses as the vendored rusty-matter fixture (the self-test checks this), and the fixture contains identifiers, normalized labels, sample counts, observation periods, drug windows and frequencies only: no region geometry, organ tables, experiment free text or images.

## Claim Boundaries

- **Empirical records (`rusty_matter_planformdb_derived_v0.json`, `planform_bioelectric_series_v1.json`)**: Report exact experiment IDs, specimen counts ($n$), observation times, drug windows, and morphology frequencies (`#1`, `#2`, `#20`, `#21`, `#24`, `#74`, `#101`, `#112`) from `PlanformDB 2.5.0`. Any link function fitted against them is an infinitemorphospace calibration and is never attributed to rusty-matter, whose source-target fixture keeps such uses blocked.
- **Mechanistic models (`2021-Cervera–Levin–Mafe.py` and `rusty_matter_planarian_traces.json`)**: Compare two qualitative/semi-quantitative mathematical abstractions of gap-junction-mediated AP polarity:
  1. **Cervera, Levin & Mafe (2021)** 1D reaction–diffusion morphogen wavefront shift $x^*(f_2)$ under gap-junction diffusivity reduction $D_X = f_2 D_{X,0}$, and
  2. **`MesmerPrism/rusty-matter` 5-band bioelectric circuit** with voltage-difference-gated gap-junction conductance, hysteresis pattern memory $M_i$, and Head/Tail readout layers (plus a memory-disabled negative control).
- Neither mechanistic abstraction claims exact biophysical voltage calibration in millivolts or direct gene-regulatory parameter fitting beyond the cited papers.

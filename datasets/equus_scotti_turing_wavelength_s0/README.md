# Equus scotti — follicular Turing wavelength (164 µm, 0.6 Ma)

Slot 3220 of the 10,000-Animal Basic Look. One animal, one scale, one horizon.

*Equus scotti* is the Middle Pleistocene (Irvingtonian, **0.6 Ma**) giant horse in the equid autopod and dental chronoseries. This slot is the **detail** wavelength of the coat melanocyte field, **164 µm** (0.0001643 m, log10 = −3.784, tier `5_primordium_100um`). It is not the 8.8 mm organ-tier stripe spacing modeled for the same species in slot 1222.

## What is formalized

Schnakenberg (1979) activator–substrate kinetics on a dermal patch, with the Turing wavenumber defined as the linear mode of fastest growth,

k_c = argmax_k σ_+(k), λ_c = 2π / k_c = 164.3 µm.

Diffusivities are solved so that this peak sits on the assigned scale. Murray’s determinant-stationary wavenumber k_m is reported beside k_c; the two estimators are not the same once the reaction is well above onset.

## Chronoseries (Equus 1/2)

| Taxon | Age | What changes at this scale |
| --- | --- | --- |
| *Pliohippus pernix* (predecessor) | 8.5 Ma | Smaller catalog linear size (0.215 vs 0.260). Follicular wavelength scaled by that ratio is 198.7 µm, so a 1.31 mm patch holds fewer modes. |
| *Equus scotti* (this slot) | 0.6 Ma | Selected wavelength 164.3 µm. About eight follicular wavelengths fit the 1.31 mm patch. |
| *Equus quagga* (successor) | extant | Bard (1977) measured a shared equid **initiation** spacing of 0.4 mm, fixed in week 3 of *E. burchelli* / plains zebra and only later stretched by growth. That 400 µm mode is coarser than the Irvingtonian follicular wavelength. |

The campaign orders *E. scotti* then *E. quagga* as Equus chronoseries 1/2. That is not a claim of direct ancestry: *E. scotti* is a North American caballoid, *E. quagga* a zebra.

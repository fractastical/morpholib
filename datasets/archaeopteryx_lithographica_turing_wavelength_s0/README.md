# Archaeopteryx lithographica — Turing wavelength at 75 µm (slot 3120)

Late Jurassic (Tithonian, **150.0 Ma**) Solnhofen Urvogel. This slot is the **detail / cellular** variant of the Theropod–Avian Feather Fossil Series, not the 2.9 mm organ-scale vane model.

| Quantity | Value |
| --- | --- |
| Phenomenon | Turing pigment stripe / ocellus wavelength |
| Scale | **75 µm** (7.478×10⁻⁵ m, log10 = −4.126, tier `4_cellular_10um`) |
| Age | **150.0 Ma**, Tithonian, Solnhofen |
| Chronoseries | Archaeopteryx **1/1** (one horizon). Lineage neighbors: *Anchiornis huxleyi* (160.8 Ma) and *Microraptor gui* (120 Ma) |
| Law | Turing wavenumber \(k_c\), Schnakenberg activator–inhibitor kinetics |
| Form | Stripes on an asymmetric flight vane |

The public-domain Berlin-slab photograph in this folder is the anatomical specimen. A whole-slab scan does not resolve 75 µm (that length is a fraction of a pixel on a ~0.5 m fossil), so the 74.78 µm wavelength is the PDE scale, while the Pearson fit is the wing optical-density transect at scan resolution. See `archaeopteryx_lithographica_turing_wavelength_s0_reference.json`.

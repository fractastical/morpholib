# Gallus gallus — Turing ocellus wavelength (slot 3228, detail s0)

Holocene (extant) red junglefowl / chick, *Gallus gallus*. Aristotelian path: I. Enaima (Vertebrata) → Aves (Ornithes) → Gallus.

This slot is one point in evolutionary history and one spatial scale:

- **Scale:** 319.2 µm (0.0003192 m, log10 = −3.496), tier `5_primordium_100um`, detail variant `s0`. The quantity is the critical Turing wavelength λ_c of a within-feather pigment stripe / ocellus.
- **Age:** 0 Ma, Holocene (Extant). The Gallus chronoseries in this campaign is 1/1: there is no predecessor chronospecies and no successor chronospecies. λ_c is therefore not inherited from a sibling fossil parameter file. What changes relative to a smaller embryonic field of the same species is the number of selected periods, N = round(L / 319.2 µm). A field shorter than one wavelength sits below the geometric cutoff and carries no ocellus; the Holocene primordium-scale patch used here is six wavelengths wide (1915.2 µm).

## Model

Schnakenberg activator–inhibitor kinetics (the same class Harris, Meinhardt, Prum and colleagues used for *Gallus* feather epithelium) with the Turing onset wavenumber

k_c² = (D_v f_u + D_u g_v) / (2 D_u D_v),    λ_c = 2π / k_c = 319.2 µm.

Parameters (a, b, D_u, D_v) = (0.2005, 0.7995, 1, 16) place the homogeneous state just above onset (margin R ≈ 1.15). The reaction scale γ is solved so that λ_c is exactly 319.2 µm. An equal-diffusion ablation (D_v = D_u) is linearly stable. Pass 2 of the loop adds the D_v sweep, that ablation, specimen computer-vision segmentation, and a held-out radial goodness-of-fit.

The rendered ocellus is the weakly nonlinear radial pattern at this k_c (fundamental plus the second and third harmonics generated by the quadratic term), amplitude-grown by the Stuart–Landau law, and compared with the canonical gallery plate.

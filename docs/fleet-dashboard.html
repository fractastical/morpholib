Aristotle's Lagoon

Plate III — Registry of the Agent Fleet, exhibited as natural history — after D'Arcy Thompson, On Aristotle as a Biologist (1913)

From the Curator. Aristotle catalogued the Lagoon of Pyrrha by presence, absence, and what each creature's form is for. This plate does the same for the agent fleet. Every agent type is represented by a species already held in the library — a real specimen photograph, pinned and labelled, not a drawing set swimming — and every number is counted from the records the repository itself keeps (cloud dispatch records, returned reports, loop telemetry). Chat-session subagents leave no repo record and are not counted. When enough morphology has been captured to let forms transform into one another, in Thompson's manner, the Evolution Gallery at the foot of the page will open. Until then: no swimming. IX. The unranked fleets — a recording gap

The 1,030 slot dispatches and the Cursor cloud fleets (100 scouts, 12 fixers) do not record which model each agent ran, so they cannot be ranked yet — the leaderboard above covers only the 106 telemetry-tracked loops. Fleet outcomes by completion are in Plate I; recording the model in every dispatch record (the fixer dispatcher already accepts --model) would make the next wave rankable end-to-end.

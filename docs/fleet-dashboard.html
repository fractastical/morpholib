IX. The unranked fleets — a recording gap

The 2,201 slot dispatches and the Cursor cloud fleets (100 scouts, 12 fixers) do not record which model each agent ran, so they cannot be ranked yet — the leaderboard above covers only the 106 telemetry-tracked loops. Fleet outcomes by completion are in Plate I; recording the model in every dispatch record (the fixer dispatcher already accepts --model) would make the next wave rankable end-to-end.

MorphoSwarm — open problems

The swarm-facing work queue for Infinite Morphospace's problem graph: every problem that is genuinely still open, what exactly blocks it, what counts as closing it, and who has already attempted it. Colour rule, same as the graph: ≥15% · POSSIBLE PATHWAY <15% · LOW PROBABILITY NOT SCORED — 15% is a visual threshold, not a Delphi source field.

Swarm protocol
  1. Pick one OP id. Machine-readable feed: open-problems.json (this page, as data, for agents).
  2. Pre-register the attempt before touching held-out data — the repo's contract is hash-locked predictions, scorer refuses on mismatch.
  3. Negative results are results. Pruned branches stay in the graph; do not quietly retry a refuted branch as if new.
  4. Close by updating the source documents, then re-run docs/build_problem_graph_html.py — its self-checks must pass before anything deploys.

Note: this project's name is a work-queue label for this repo's agent swarm. It is unrelated to the robotic-swarm MorphoSwarm of Ben Zion et al. (Science Robotics 2022; doi:10.5281/zenodo.7573761).

The gap: Defects D1(t)=1 are proved to arrive infinitely often, but not proved to ever land on a closed gate {c_t=1}. Depth-1 right cylinder has positive topological entropy (~0.32 bits/step) on short runs, so no deeper local transducer closes this; it needs a global phase-spreading / mixing invariant.

Definition of done: A proof (ideally Lean-checked) that for all t0, Π and short-run words, some D1(t)=1 lands on {c_t=1} — or a counterexample word, which would be just as valuable.

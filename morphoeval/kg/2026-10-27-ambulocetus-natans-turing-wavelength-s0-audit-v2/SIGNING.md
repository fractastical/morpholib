# Signing

`~/.nanopub/profile.yml` is not present in this environment, so `morphoeval/sign_morphoeval.py` was not run and `node morphoeval/check_signed.mjs` had nothing to verify.

The TriG files in this directory are unsigned. No trusty URI was invented. Pass 2 supersedes the pass-1 audit in the audit YAML (`supersedes_audit_id`), not by a signed `npx:supersedes` link.

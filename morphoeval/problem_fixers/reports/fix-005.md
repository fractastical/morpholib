# Problem-Fixer fix-005 — Global morphogenetic flow seed DOI

**Candidate:** LIB-DQ-GMF-01 (rank 10)  
**Branch:** `morphoeval/fixer-fix-005-global-morphogenetic-flow-doi`  
**Status:** fixed

## Finding

Slot 048 (`datasets/global_morphogenetic_flow`) had split landmark provenance:

| Source | DOI | Title evidence |
|--------|-----|----------------|
| `scout_manifest.json` `territory.seed_doi` (before) | `10.7554/eLife.35326` | Matches `seed_landmark_paper` text (Streichan 2018 global morphogenetic flow) |
| `paper_citations.bib` entry 1 | `10.7554/eLife.27454` | *Global morphogenetic flow is accurately predicted by the spatial distribution of myosin* |
| `global_morphogenetic_flow_reference.json` | `10.7554/eLife.27454` | Same Streichan (2018) citation |

External verification (2026-10-27):

- **Primary (27454):** Crossref resolves to Streichan et al. (2018), title *Global morphogenetic flow is accurately predicted by the spatial distribution of myosin motors*, DOI `10.7554/elife.27454`. eLife article identifier `e27454`.
- **Scout seed (35326):** Crossref returns *Resource not found*; `https://doi.org/10.7554/eLife.35326` returns HTTP 404. This is not a second, distinct article—there is nothing to keep as a secondary citing DOI.

## Root cause

The scout dossier recorded a non-resolving eLife DOI while the dataset’s bib and reference JSON were already correct. The mismatch is a scout provenance error (likely digit transposition), not two valid eLife records for the same slot.

## Fix

1. Set `territory.seed_doi` to `10.7554/eLife.27454`.
2. Record the old value as `territory.seed_doi_superseded`: `10.7554/eLife.35326` (audit trail, not a citation).
3. Add top-level `seed_doi_correction` documenting fix-005 and the Crossref/doi.org check.

No change to `paper_citations.bib` or `global_morphogenetic_flow_reference.json` (they were already authoritative).

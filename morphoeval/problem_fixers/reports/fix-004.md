# Problem-Fixer fix-004 — Newman limb `seed_doi` typo (LIB-DQ-LIMB-01)

## Finding

`datasets/limb_chondrogenesis_turing/scout_manifest.json` had `territory.seed_doi` set to **`10.1126/science.472739`**, while the slot’s canonical bibliography and reference metadata already cited **`10.1126/science.462174`** for Newman & Frisch (1979) *Science* 205(4407):662–668.

Crossref verification (2026-10-27):

| DOI | Crossref title | First author | Date |
|-----|----------------|--------------|------|
| `10.1126/science.462174` | Dynamics of Skeletal Pattern Formation in Developing Chick Limb | Newman | 1979-08-17 |
| `10.1126/science.472739` | Geographic Constraints on Women's Careers in Academia | Marwell | 1979-09-21 |

The erroneous DOI is a real, unrelated *Science* article—not a valid alias for the Newman paper.

## Root cause

The scout dossier likely introduced a **digit transposition** when recording the seed DOI. The reference JSON (`metadata.sources[0].doi`) and `paper_citations.bib` were authored correctly; only the scout manifest provenance field was wrong.

## Fix

1. Set `territory.seed_doi` to `10.1126/science.462174`.
2. Add `pass3_correction` on the scout manifest (same convention as `datasets/zebrafish_three_cell_stripes/scout_manifest.json`) documenting the old DOI, Crossref evidence, and fix id **fix-004**.
3. Update the embedded `metadata.scout_manifest.sha256` in `limb_chondrogenesis_turing_reference.json` and the README digest line so in-dataset provenance stays self-consistent.

**Old → new DOI:** `10.1126/science.472739` → `10.1126/science.462174`

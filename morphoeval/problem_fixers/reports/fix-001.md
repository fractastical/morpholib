# Problem-Fixer fix-001 — bioelectric_polarity alpha-template artifacts

## Finding

All three core `*_bioelectric_polarity_reference.json` files (Danio rerio slot 931, Xenopus tropicalis slot 921, Drosophila melanogaster slot 941) carry `empirical_series` curves that match the overnight catalog generator in `morphoeval/run_overnight_1000_loops.py` (lines 592–633): fixed `x_control` grid on `[0.5, 5.0]`, `alpha_scale` and `beta_offset` derived from slot arithmetic, and Gaussian noise around `alpha_scale * x^1.25 + beta_offset`.

Pearson checks requested by scout candidate BIO-TPL-DQ-01 all pass on the unchanged JSON:

| Dataset | r(y_emp, α·x) | r(y_emp, y_sim) | poson_law |
|---------|---------------|-----------------|-----------|
| danio_rerio | 0.997759 | 0.999472 | Bistable V_mem / G_ij Threshold |
| drosophila_melanogaster | 0.996998 | 0.999601 | same |
| xenopus_tropicalis | 0.998641 | 0.999196 | same |

Fitting the full slot formula gives r ≈ 0.9993–0.9997 against `y_empirical`, confirming the series is synthetic template noise rather than literature digitisation. `paper_citations.bib` and `scout_manifest.json` seed DOIs name real territories but do not pin figure-level measurements for these 12 points.

## Root cause

The 1000-loop expansion scaffold writes reference JSON before independent empirical curation. Bioelectric polarity slots reused that scaffold; downstream MorphoEval audits then scored high `pearson_r` parity as morphometric validation against those DOIs.

## Fix

1. **Machine checker** — `morphoeval/problem_fixers/check_bioelectric_template_artifact.py` (BIO-TPL-DQ-01) re-computes correlations and slot-parameter derivation on every run.
2. **Audit artifact** — `morphoeval/audits/2026-10-27-bioelectric-polarity-alpha-template-data-quality.yaml` lists affected paths, exact correlations, and downstream claims that must not treat these curves as biology.
3. **Quarantine manifest** — `morphoeval/problem_fixers/quarantine/BIO-TPL-DQ-01_manifest.json`.
4. **Dataset labelling** — `empirical_series_provenance` blocks added to the three reference JSON files (numeric series unchanged) plus README quarantine sections.

Registration in `predictions/build_prediction_registry.py` was **not** performed: path allowlist forbids edits outside `morphoeval/problem_fixers/**`, dataset dirs, and `morphoeval/audits/*bioelectric*data-quality*.yaml`. The in-repo quarantine supersedes the scout’s registry route for this wave.

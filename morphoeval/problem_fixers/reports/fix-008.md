# Problem-Fixer fix-008 — Zhang sorting math-KG Rule 3

## Finding

`python3 morphoeval/verify_integrity.py --loop-yaml morphoeval/math_kg_loops/zhang-sorting-morphogenesis.yaml` failed with **four** Rule 3 violations before this fix. Laws 1 (Bubble barrier pinning) and 4 (Selection non-local swap) already passed because their `lean_code` blocks began with quantified structural theorem signatures from `morphoeval/lean/loops/Loop_zhang_sorting_morphogenesis.lean`.

## Root cause

Rule 3 classifies only the **first** `theorem` in each equation’s `lean_code` field (`morphoeval/verify_integrity.py`, `classify_lean_theorem_signature`). Several Zhang equations either:

- Led with ground `by decide` witness theorems (laws 2, 5, 6), or
- Listed the ground Lyapunov projection artifact **before** the cited structural theorem `adjacent_swap_strictly_decreases_inversions_window3` (law 3),

so the gate reported `ground_arithmetic` even though the Loop file contains the intended structural signatures at the declared `lean_locus` ranges.

## Fix

| 2 Insertion prefix-reset | Expanded `lean_locus` to `#L30-L129`; `lean_code` now includes Bubble barrier defs/theorem (legal adjacent swap context for Insertion) plus the full prefix-reset fold defs and the existing ground insertion witness theorem unchanged from Lean. |

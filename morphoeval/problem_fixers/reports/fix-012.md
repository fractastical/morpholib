# Problem-Fixer fix-012 — DM-DPP-01 Lean mobility certificate

## Finding

Prediction **DM-DPP-01** was already **confirmed** in `predictions/resolutions/inrepo-quick.json` using
`sequences/sequence_links.json` and informal cube-root arithmetic. There was no standalone Lean loop
that machine-checks the registered factors **0.61** (D_precursor/D_mature under the MW^(-1/3) prior)
and **0.78** (associated length-scale ratio).

## Root cause

The in-repo quick resolution path documented the biology and arithmetic in prose JSON only. Scout
**scout-063-c** correctly identified a proof gap: finite rational comparisons suitable for Lean
`decide` were never formalized under `morphoeval/lean/loops/`.

## Fix

1. **`morphoeval/lean/loops/Loop_prediction_DM_DPP_01_dpp_mobility_ratio.lean`**
   - Freezes P07713 lengths: mature chain **132 aa** (457–588), precursor **588 aa**.
   - Proves mobility ratio **R = (132/588)^(1/3)** via Nat inequalities:
     - `607/1000 < R < 608/1000` (tight bracket)
     - `R < 610/1000` (includes registered nominal **0.61**)
   - Proves length-scale factor **(132/588)^(1/6)** with `779/1000 < L ≤ 780/1000` (registered **0.78**).
   - Theorem names prefix `dm_dpp_01_` for traceability to **DM-DPP-01**.

2. **`tests/test_problem_fixer_dm_dpp.py`**
   - Reads `sequences/sequence_links.json` and asserts the same integers.
   - Replicates the integer bound checks in Python.
   - Runs the repo’s no-`sorry` scan and invokes `lean` when available.

The locked prediction registry was **not** modified.

# Problem-Fixer fix-006: Turing audit `script:` path

## Finding

Running `measure_turing()` with the audit-declared script path `1952-turing-morpho.py` at repo root produced **4** measurement rows (GIF pixel metrics only). The checked-in entrypoint is **`models/1952-turing-morpho.py`**, which yields **10** rows including Pearson 1993 and Kondo & Asai 1995 `reference_source` fields.

The v2 audit sidecar had previously held 10 rows (likely from an era when the script lived at root or was measured manually). After script relocation, re-running `measure_outputs.py` without fixes dropped script-backed rows silently.

## Root cause

1. **Audit YAML** — `2026-10-19-turing-audit-v2.yaml` and `2026-10-26-flagship15-audit-v1.yaml` set `script: 1952-turing-morpho.py` (root-relative), but no such file exists.
2. **`measure_turing()`** — Script import and `run_pearson_morphospace_analysis()` ran only when `turing_script.exists()`; otherwise the function returned the partial GIF list with no error row.
3. **GIF input for v2 audit** — Primary `output: turing_pearson_morphospace.png` is not present in this checkout; GIF morphometrics require falling back to `extra_outputs` (`docs/media/turing_gray_scott.gif`).

## Fix

| Layer | Change |
|-------|--------|
| Audits | Set `script: models/1952-turing-morpho.py` on both Turing audits (matches other MorphoEval audits). |
| `measure_outputs.py` | Added `resolve_script_path()` (legacy bare basename → `models/<basename>`). Default Turing script path updated to `models/1952-turing-morpho.py`. When the script is still missing, append an explicit **skipped** measurement row instead of a silent partial result. For `turing-gray-scott`, prefer an existing GIF/WebP from `extra_outputs` when the declared output is not an on-disk animation. |
| Tests | `tests/test_problem_fixer_turing_measurements.py` — completeness, legacy resolution, visible skip on bogus path, full sidecar regeneration. |
| Sidecars | Regenerated via repo tool (not hand-edited values). |
